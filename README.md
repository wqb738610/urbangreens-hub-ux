# UrbanGreens Hub - Web App UX Design

UrbanGreens Hub is a proposed web application for a Melbourne environmental non-profit. The project focuses on helping users discover volunteer events, explore a Green Map, register for activities, and giving staff a clearer admin workflow for event and impact management.

## Project Type

UX design, information architecture, requirements analysis, low-fidelity Figma prototyping.

## My Contribution

- Defined the project context, target users, user needs, and core platform workflows.
- Created personas and scenarios for public volunteers, community members, and non-profit staff.
- Designed the sitemap and low-fidelity wireframes for event registration, Green Map discovery, and admin dashboard workflows.
- Mapped business needs into UX requirements such as form validation, accessibility-aware filtering, geo-location discovery, and role-based admin concepts.
